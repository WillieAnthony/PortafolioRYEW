Sobre mí

Soy estudiante de Ingeniería en Software apasionado por el desarrollo de aplicaciones y la resolución de problemas complejos. Me gusta aprender nuevas tecnologías y aplicarlas en proyectos innovadores.

Mi objetivo es contribuir al desarrollo de soluciones tecnológicas que mejoren la vida de las personas.

Proyectos Completados

Tienda de Abarrotes (2024)

Desarrollé un sistema integral para la gestión de inventario y ventas de una tienda de abarrotes. Este proyecto incluye un panel de administrador que permite almacenar y modificar productos, así como agregar nuevos administradores. Los usuarios pueden navegar por el catálogo de productos, realizar compras y generar tickets en formato PDF. Se implementó utilizando Java para la lógica del backend y MySQL como base de datos.

Calculadora Científica (2023)

Desarrollé una calculadora científica interactiva utilizando HTML, CSS y JavaScript. Esta aplicación permite realizar operaciones matemáticas avanzadas, como funciones trigonométricas, logarítmicas y exponenciales. La interfaz gráfica fue diseñada con un enfoque moderno y responsivo, garantizando una experiencia de usuario óptima en dispositivos móviles y escritorios.

Memorama (2023)

Desarrollé un juego de memoria interactivo utilizando HTML, CSS y JavaScript. Este proyecto consiste en un tablero dinámico donde los jugadores deben encontrar parejas de cartas iguales. Implementé funcionalidades como temporizadores, puntuaciones y niveles de dificultad. El diseño visual fue optimizado para proporcionar una experiencia atractiva y accesible.

Juego "Snake" (2023)

Implementé una versión clásica del juego "Snake" utilizando HTML, CSS y JavaScript. Este proyecto incluye características como movimiento fluido del personaje, detección de colisiones y generación aleatoria de alimentos. Además, se añadió un sistema de puntuación y niveles progresivos para mantener al jugador comprometido. El diseño gráfico fue cuidadosamente elaborado para evocar nostalgia mientras mantiene un aspecto moderno.

Proyectos en Elaboración

Portafolio WEB (2025)

Actualmente estoy desarrollando este portafolio web con el objetivo de presentar mis habilidades y proyectos de manera profesional. Este sitio servirá como una herramienta clave para destacar mi trayectoria académica y profesional, así como para conectar con posibles empleadores o colaboradores. Sistema de Catálogo de Películas (2025)

Estoy trabajando en un sistema de catálogo de películas que permitirá a los usuarios buscar, filtrar y organizar sus películas favoritas. Este proyecto está siendo desarrollado en Java y contará con una interfaz gráfica intuitiva. Entre sus características destacan la clasificación por género, año de lanzamiento y calificación. Se espera que este sistema sea útil tanto para entusiastas del cine como para pequeñas empresas de alquiler de películas.

Sitio WEB de "Tienda de Productos" (2025)

Este proyecto consiste en el desarrollo de un sitio web completo para una tienda de productos, donde los usuarios podrán explorar, comprar y pagar mediante PayPal. El administrador tendrá acceso a un panel para gestionar inventarios, agregar productos y supervisar transacciones. Se está utilizando React para la interfaz frontend, Laravel para el backend y MySQL como base de datos. Además, se están incorporando tecnologías como Tailwind CSS para el diseño responsivo.

Videojuego "Pecados Capitales" (2025)

Estoy desarrollando un videojuego inspirado en los siete pecados capitales utilizando Unity y C#. Este juego combina elementos de acción y aventura, permitiendo a los jugadores enfrentarse a desafíos basados en cada uno de los pecados. Se está implementando una mecánica innovadora de decisiones morales que afectan el desarrollo de la historia. El proyecto también incluye modelos 3D y animaciones hechas en Blender.
